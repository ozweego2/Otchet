# Лабораторная работа № 5

## Тема
Работа с распределённой системой контроля версий Git и удалённым репозиторием GitHub.

## Цель работы
Освоить создание и использование веток, фиксацию изменений коммитами, работу с pull request и слияние веток.

## Выполненная работа

1. Использован репозиторий [ozweego2/Otchet](https://github.com/ozweego2/Otchet).
2. В репозитории созданы и сохранены три ветки:
   - `main`;
   - `вторая-ветвь`;
   - `третья-ветвь`.
3. В ветке `main` доработан учебный сайт PixelPlay: в каталоге игр добавлена интерактивная фильтрация по жанрам.
4. Во второй ветке добавлен файл `notes/branch-two.txt`.
5. В третьей ветке добавлен файл `data/game-notes.json`.
6. Для изменений созданы отдельные коммиты и pull request.
7. Изменения обеих веток слиты в `main` merge-коммитами.

## Результат
В репозитории присутствуют ветки, история коммитов, pull request и итоговая версия проекта в ветке `main`.

## Вывод
В ходе работы освоены базовые операции Git и GitHub: работа с ветками, создание коммитов, pull request и слияние изменений.
